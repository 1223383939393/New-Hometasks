
**Deque** (произносится «дек», сокращение от *Double Ended QUEue*) — это двусторонняя очередь. В отличие от обычной очереди, где элементы добавляются с одного конца, а извлекаются с другого, дек позволяет добавлять, удалять и просматривать элементы с обоих концов.

* **Аналогия:** Представь трубу, в которую можно класть и брать мячики с обеих сторон. Это и есть дек.
* **Ключевая особенность:** `Deque` может работать и как стек, и как очередь — всё зависит от того, какие методы ты используешь.

---

## Зачем нужен дек?

**Дек (Deque)** нужен в ситуациях, когда требуется быстрый доступ, добавление и удаление элементов **с обоих концов** коллекции за константное время $O(1)$. Основные сценарии использования:

* Реализация **очереди (FIFO)** и **стека (LIFO)** с помощью одного универсального интерфейса.
* Задачи со **скользящим окном** (поиск минимума или максимума на отрезке массива).
* Проверка строк на **палиндром** (сравнение символов с начала и с конца).
* Реализация истории действий (Undo/Redo) с ограничением по размеру, когда старые записи удаляются с одного конца, а новые добавляются с другого.

## Способ реализации Деков в Java и отличия

В Java `Deque` — это интерфейс из пакета `java.util`, который имеет две основные реализации: **`ArrayDeque`** и **`LinkedList`**.

### Пример создания дека
```java
import java.util.Deque;
import java.util.ArrayDeque;

Deque<Integer> deque = new ArrayDeque<>();
Deque<String> names = new ArrayDeque<>();
```

### Основные отличия реализаций
* **`ArrayDeque`** построен на основе кольцевого динамического массива. Он работает быстрее, занимает меньше памяти и является рекомендуемым выбором по умолчанию. Не позволяет хранить `null`.
* **`LinkedList`** построен на основе двусвязного списка (каждый элемент хранит ссылки на предыдущий и следующий). Потребляет больше памяти из-за хранения ссылок на соседние узлы, но разрешает добавление `null` и эффективнее при удалении элементов из середины во время итерации.

---

## Основные методы реализации через ArrayDeque (Добавление и удаление)

| Метод | Что делает | Пример |
| :--- | :--- | :--- |
| `addFirst(e)` / `offerFirst(e)` | Добавляет элемент в начало дека (`offerFirst` возвращает `false` при неудаче, `addFirst` кидает исключение). | `deque.addFirst(10);` |
| `addLast(e)` / `offerLast(e)` | Добавляет элемент в конец дека. | `deque.offerLast(20);` |
| `removeFirst()` / `pollFirst()` | Удаляет и возвращает первый элемент (`pollFirst` вернет `null`, если дек пуст). | `int first = deque.pollFirst();` |
| `removeLast()` / `pollLast()` | Удаляет и возвращает последний элемент (`pollLast` вернет `null`, если дек пуст). | `int last = deque.pollLast();` |

### Пример
```java
Deque<Integer> deque = new ArrayDeque<>();
deque.addFirst(10);  // [10]
deque.addLast(20);   // [10, 20]
deque.offerFirst(5); // [5, 10, 20]

System.out.println(deque.pollFirst()); // Выведет 5, останется [10, 20]
System.out.println(deque.pollLast());  // Выведет 20, останется [10]
```

## Основные методы реализации через ArrayDeque (Просмотр и работа как стек/очередь)

| Метод | Что делает | Пример |
| :--- | :--- | :--- |
| `getFirst()` / `peekFirst()` | Возвращает первый элемент **без удаления** (`peekFirst` вернет `null`, если дек пуст). | `Integer head = deque.peekFirst();` |
| `getLast()` / `peekLast()` | Возвращает последний элемент **без удаления** (`peekLast` вернет `null`, если дек пуст). | `Integer tail = deque.peekLast();` |
| `push(e)` | Работа как **стек**: кладет элемент на вершину (в начало дека). Аналог `addFirst()`. | `deque.push(100);` |
| `pop()` | Работа как **стек**: забирает элемент с вершины (из начала дека). Аналог `removeFirst()`. | `int top = deque.pop();` |

### Пример
```java
Deque<String> stack = new ArrayDeque<>();
stack.push("Первый");
stack.push("Второй");

System.out.println(stack.peekFirst()); // Выведет "Второй" (элемент остался в деке)
System.out.println(stack.pop());       // Выведет "Второй" (элемент удален)
System.out.println(stack.getLast());   // Выведет "Первый"
```

## Сравнительная таблица ArrayDeque vs LinkedList

| Критерии | ArrayDeque | LinkedList |
| :--- | :--- | :--- |
| **Внутренняя структура** | Кольцевой динамический массив | Двусвязный список (узлы со ссылками) |
| **Потребление памяти** | Меньше (хранятся только сами элементы) | Больше (дополнительная память на ссылки `prev` и `next`) |
| **Скорость работы (кэш CPU)** | Выше (элементы лежат в памяти подряд) | Ниже (узлы разбросаны по куче памяти) |
| **Поддержка `null`** | Запрещено (выбросит `NullPointerException`) | Разрешено |
| **Реализуемые интерфейсы** | Только `Deque` (и `Queue`) | `Deque`, `Queue` и `List` (доступ по индексу) |
