**Очередь (Queue)** — это структура данных, работающая по принципу **FIFO** (*First In, First Out* — «первым пришёл, первым вышел»).

Представь очередь в магазине:
* Новый покупатель встаёт в конец — `offer` / `add`.
* Обслуживают первого в очереди — `poll` / `remove`.
* Посмотреть, кто первый, не выгоняя его — `peek` / `element`.
* Именно так работает очередь.

---

### Зачем нужна очередь?

Очередь нужна там, где важно обрабатывать данные или запросы **строго в том порядке, в котором они поступили**:

* **Обработка запросов на сервере:** Пользователи отправляют запросы, и сервер выполняет их по порядку поступления, чтобы никого не пропустить.
* **Очередь печати или задач:** Документы отправляются на принтер и печатаются друг за другом.
* **Обход графов и деревьев в ширину (BFS):** Алгоритм постепенно проверяет соседние элементы уровень за уровнем.
* **Буферизация данных:** Потоковая передача видео или аудио, где пакеты данных должны воспроизводиться в правильном порядке.

---

### Способ реализации очереди в Java и отличия

В Java `Queue` — это интерфейс, поэтому создать его напрямую через `new Queue<>()` нельзя. Используются конкретные классы-реализации:

1. **`java.util.ArrayDeque` (рекомендуемый способ)**
   Двусторонняя очередь на основе динамического массива.
   * **Плюсы:** Работает быстрее за счёт непрерывного хранения в памяти, не тратит лишнюю память на ссылки.
   * **Ограничения:** Не разрешает добавлять `null` (выдаст `NullPointerException`).
2. **`java.util.LinkedList` (классический способ)**
   Двусвязный список, реализующий интерфейсы `List` и `Queue`.
   * **Плюсы:** Позволяет хранить `null` и поддерживает работу по индексам как обычный список.
   * **Минусы:** Работает медленнее `ArrayDeque` и занимает больше памяти, так как для каждого элемента создаётся отдельный узел со ссылками на соседей.
3. **`java.util.PriorityQueue` (очередь с приоритетом)**
   Особая очередь, где элементы выходят не по порядку добавления, а **по приоритету** (по умолчанию — от меньшего к большему).

---

### Основные методы каждого вида реализации

У всех реализаций интерфейса `Queue` набор методов одинаковый. Они делятся на две группы: одни при ошибке выбрасывают исключение, а другие возвращают специальное значение (`false` или `null`).

| Метод | Что делает | Пример |
| :--- | :--- | :--- |
| `offer(item)` | Добавляет элемент в конец очереди (вернёт `false`, если нет места) | `queue.offer("П1");` |
| `add(item)` | Добавляет элемент в конец очереди (выбросит ошибку, если нет места) | `queue.add("П1");` |
| `poll()` | Забирает и удаляет первый элемент (вернёт `null`, если очередь пуста) | `String first = queue.poll();` |
| `remove()` | Забирает и удаляет первый элемент (выбросит ошибку, если очередь пуста) | `String first = queue.remove();` |
| `peek()` | Показывает первый элемент без удаления (вернёт `null`, если пусто) | `String first = queue.peek();` |
| `element()` | Показывает первый элемент без удаления (выбросит ошибку, если пусто) | `String first = queue.element();` |
| `isEmpty()` | Проверяет, пуста ли очередь (`true` или `false`) | `if (queue.isEmpty())` |
| `size()` | Возвращает текущее количество элементов в очереди | `int count = queue.size();` |

*(Примечание: для `PriorityQueue` методы `poll()` и `peek()` всегда будут работать с элементом, у которого наивысший приоритет, а не с тем, кто пришёл первым).*

### Пример каждого вида реализации

#### 1. Обычная очередь на базе `ArrayDeque` (основной вариант)
```java
import java.util.ArrayDeque;
import java.util.Queue;

Queue<String> queue = new ArrayDeque<>();
queue.offer("Первый");
queue.offer("Второй");

System.out.println(queue.peek()); // Выведет: Первый (остаётся в очереди)
System.out.println(queue.poll()); // Выведет: Первый (удаляется из очереди)
System.out.println(queue.poll()); // Выведет: Второй
```

#### 2. Очередь на базе `LinkedList`
```java
import java.util.LinkedList;
import java.util.Queue;

Queue<Integer> queue = new LinkedList<>();
queue.offer(10);
queue.offer(20);
queue.offer(null); // LinkedList позволяет добавить null

System.out.println(queue.poll()); // Выведет: 10
```

#### 3. Очередь с приоритетом `PriorityQueue`
```java
import java.util.PriorityQueue;
import java.util.Queue;

Queue<Integer> priorityQueue = new PriorityQueue<>();
priorityQueue.offer(30);
priorityQueue.offer(10);
priorityQueue.offer(20);

// Элементы выйдут в порядке возрастания, а не добавления
System.out.println(priorityQueue.poll()); // Выведет: 10
System.out.println(priorityQueue.poll()); // Выведет: 20
```

### Задания

#### Задача 1. Симуляция очереди в магазине
В магазине один кассир. Покупатели подходят каждую минуту. Обслуживание одного покупателя занимает X минут. Симуляция длится N минут.

Нужно:
* Каждую минуту добавлять нового покупателя в очередь.
* Если кассир свободен и очередь не пуста — обслуживать первого.
* В конце вывести:
  * сколько покупателей обслужено,
  * сколько осталось в очереди.

Пользователь вводит X и N.

Пример вывода для X = 2 и N = 10:
```text
Минута 1: пришёл П1
Минута 1: обслуживается П1
Минута 2: пришёл П2
Минута 3: пришёл П3
Минута 3: обслуживается П2
...
Обслужено: 5
Осталось в очереди: 5
```

#### Задача 2. Игра «Горячая картошка»
N игроков встают в круг. Ведущий считает до K. На счёт K игрок выбывает. Счёт продолжается со следующего. Последний оставшийся — победитель.

Реализуй через очередь:
* Все игроки — в очереди.
* K−1 раз: `poll` + `offer` (перекладываем из начала в конец).
* На K-й раз: `poll` — выбывает.
* Повторяем, пока в очереди не останется один.

Пользователь вводит N и K.

Пример: игроки `[A, B, C, D, E]`, K = 3.
```text
Считаем: A, B, C → C выбывает
Осталось: [D, E, A, B]
Считаем: D, E, A → A выбывает
Осталось: [B, D, E]
Считаем: B, D, E → E выбывает
Осталось: [B, D]
Считаем: B, D, B → B выбывает
Победитель: D
```

#### Задача 3. Круговая обработка задач
Есть N задач, каждая требует определённого числа тиков для завершения. Процессор выполняет задачи по кругу: берёт из начала, выполняет 1 тик, если задача не завершена — кладёт в конец.

Выведи порядок выполнения и время завершения каждой задачи.
Пользователь вводит задачи и их размер.

Пример:
```text
Задачи: A=3, B=2, C=1
Тик 1: A
Тик 2: B
Тик 3: C
Тик 4: A
Тик 5: B
Тик 6: A → A завершена

Завершение:
A: тик 6
B: тик 5
C: тик 3
```

arr = [1, 3, -1, -3, 5, 3, 6, 7], k = 3
