# Создание библиотеки подпрограмм в Java

## 1. Что такое библиотека подпрограмм

Библиотека подпрограмм — это набор готовых методов, которые можно повторно использовать в разных программах.

В учебном примере библиотеку удобно представить как один класс с методами для похожих задач. В крупных проектах библиотека может состоять из нескольких классов и пакетов. Пакет — группа связанных классов и других типов Java.

Например, библиотека `NumberUtils` может содержать методы для нахождения большего числа, проверки чётности и вычисления среднего арифметического.

Главная идея: один раз написать метод, а затем вызывать его там, где он нужен.

## 2. Зачем нужна библиотека подпрограмм

Библиотека помогает отделить готовые операции от основной программы и не писать одинаковый код несколько раз.

Вместо повторения проверки:

```java
number % 2 == 0
```

можно создать метод и вызывать его:

```java
NumberUtils.isEven(number);
```

Аналогичный подход используется в стандартном классе `Math`, например: `Math.sqrt(25)`.

### Преимущества

1. Повторное использование: один метод можно вызывать много раз.
2. Сокращение дублирования: алгоритм не нужно копировать.
3. Удобство исправления: достаточно изменить реализацию в одном месте.
4. Понятность: имя метода объясняет его назначение.
5. Удобство проверки: методы можно проверять отдельно.

В нашей практике основная программа отвечает за вывод, а библиотека — за вычисления.

## 3. Основные характеристики библиотеки

1. Общее назначение: методы решают связанные задачи.
2. Понятный интерфейс: по названию, параметрам и результату понятно, как использовать метод.
3. Доступность: класс и методы для использования из других пакетов объявляются `public`.
4. Независимость: методы получают данные через параметры и возвращают результат через `return`.
5. Документированность: описаны назначение, параметры, результат и возможные ошибки.
6. Проверяемость: подготовлены входные данные и ожидаемые результаты.

### Шаблон статического метода

```java
public static типРезультата имяМетода(параметры) {
    // Действия метода
    return результат;
}
```

Это схема, а не готовый компилируемый код: слова `типРезультата`, `имяМетода` и `параметры` нужно заменить.

Пример:

```java
public static int max(int a, int b) {
    if (a > b) {
        return a;
    }
    return b;
}
```

Разбор:

- `public` — метод доступен из других классов.
- `static` — метод относится к классу, объект создавать не нужно.
- `int` — тип возвращаемого значения.
- `max` — имя метода.
- `int a, int b` — входные параметры.
- `return` — возвращает результат и завершает выполнение метода.

Вызов:

```java
int result = NumberUtils.max(7, 12);
```

`7` и `12` — аргументы: конкретные значения для параметров `a` и `b`. Количество и типы аргументов должны соответствовать объявлению метода.

## 4. Как правильно называть библиотеки

Для практики используем следующие правила:

1. Классы называем с большой буквы; каждое следующее слово тоже начинается с большой: `NumberUtils`, `ArrayUtils`, `StringUtils`.
2. Методы называем с маленькой буквы; следующие слова — с большой: `max`, `isEven`, `calculateAverage`.
3. Название должно отражать назначение, а не номер задания.

Хорошие названия: `NumberUtils`, `ArrayUtils`, `StringUtils`.

Неудачные названия: `Class1`, `Something`, `MyLibrary123`.

Пакеты объединяют связанные классы:

```java
package mylibrary;
```

Чтобы использовать класс из другого пакета по короткому имени:

```java
import mylibrary.NumberUtils;
```

`import` не копирует код и не подключает отсутствующую библиотеку. Он позволяет использовать короткое имя уже доступного класса.

## 5. Документация библиотеки

Документация объясняет назначение библиотеки, работу методов, параметры, результат и возможные ошибки.

В Java используется Javadoc. Комментарий начинается с `/**` и располагается перед объявлением класса или метода. Инструмент `javadoc` может создать из таких комментариев HTML-документацию.

```java
/**
 * Возвращает большее из двух целых чисел.
 *
 * @param a первое число
 * @param b второе число
 * @return большее из чисел a и b
 */
public static int max(int a, int b) {
    if (a > b) {
        return a;
    }
    return b;
}
```

Основные теги:

- `@param` — описание параметра.
- `@return` — описание результата.
- `@throws` — описание исключения и условия его возникновения.

Документация должна объяснять поведение метода. Например, для вычисления среднего нужно указать, что произойдёт при передаче пустого массива.

## 6. Как написать библиотеку: пошаговый пример

### Шаг 1. Определить назначение и методы

Создадим три метода:

```java
max(int a, int b)          // Результат: int
isEven(int number)        // Результат: boolean
average(int[] numbers)    // Результат: double
```

Это краткий план методов, а не полные объявления.

### Шаг 2. Создать структуру файлов

```text
src/
├── mylibrary/
│   └── NumberUtils.java
└── Main.java
```

В начале `NumberUtils.java` будет объявление `package mylibrary;`.

### Шаг 3. Написать библиотеку

Полный код файла `NumberUtils.java`:

```java
package mylibrary;

/**
 * Вспомогательные методы для работы с числами.
 */
public final class NumberUtils {

    private NumberUtils() {
        // Объекты этого класса создавать не нужно.
    }

    /**
     * Возвращает большее из двух целых чисел.
     *
     * @param a первое число
     * @param b второе число
     * @return большее число; если числа равны — это же значение
     */
    public static int max(int a, int b) {
        if (a > b) {
            return a;
        }
        return b;
    }

    /**
     * Проверяет число на чётность.
     *
     * @param number проверяемое число
     * @return true, если число чётное; иначе false
     */
    public static boolean isEven(int number) {
        return number % 2 == 0;
    }

    /**
     * Вычисляет среднее арифметическое элементов массива.
     *
     * @param numbers непустой массив целых чисел
     * @return среднее арифметическое
     * @throws IllegalArgumentException если массив равен null
     *                                  или не содержит элементов
     */
    public static double average(int[] numbers) {
        if (numbers == null || numbers.length == 0) {
            throw new IllegalArgumentException(
                "Массив не должен быть null или пустым"
            );
        }

        double sum = 0;

        for (int number : numbers) {
            sum += number;
        }

        return sum / numbers.length;
    }
}
```

### Шаг 4. Разобрать логику

#### Метод max

```java
if (a > b) {
    return a;
}
return b;
```

Если `a` больше `b`, возвращается `a`. Иначе возвращается `b`.

```java
NumberUtils.max(8, 3); // 8
NumberUtils.max(4, 9); // 9
NumberUtils.max(5, 5); // 5
```

#### Метод isEven

```java
return number % 2 == 0;
```

`%` вычисляет остаток от деления. Если остаток от деления на 2 равен нулю, результат проверки — `true`.

```java
NumberUtils.isEven(8);  // true
NumberUtils.isEven(7);  // false
NumberUtils.isEven(0);  // true
NumberUtils.isEven(-4); // true
```

#### Метод average

Сначала проверяем входные данные:

```java
if (numbers == null || numbers.length == 0)
```

- `numbers == null` — вместо массива передана пустая ссылка.
- `numbers.length == 0` — массив существует, но элементов в нём нет.
- `||` означает «или». Если первая проверка истинна, вторая не выполняется, поэтому обращения к длине отсутствующего массива не произойдёт.

При недопустимых данных метод выбрасывает исключение с пояснением.

Затем складываем элементы:

```java
double sum = 0;

for (int number : numbers) {
    sum += number;
}
```

Цикл по очереди берёт каждый элемент массива. Запись `sum += number` означает `sum = sum + number`.

Для `{3, 4, 6}` сумма равна 13. Далее делим её на количество элементов:

```java
return sum / numbers.length;
```

Переменная `sum` имеет тип `double`, поэтому результат может содержать дробную часть.

#### Зачем final и закрытый конструктор

```java
public final class NumberUtils
```

`final` запрещает создавать классы-наследники `NumberUtils`.

```java
private NumberUtils() {
}
```

Закрытый конструктор не позволяет снаружи написать `new NumberUtils()`. Объект не нужен, потому что все методы статические.

### Шаг 5. Использовать библиотеку

Полный код файла `Main.java`:

```java
import mylibrary.NumberUtils;

public class Main {
    public static void main(String[] args) {
        int maximum = NumberUtils.max(7, 12);
        System.out.println("Большее число: " + maximum);

        boolean even = NumberUtils.isEven(8);
        System.out.println("Число 8 чётное: " + even);

        int[] numbers = {3, 4, 6};
        double result = NumberUtils.average(numbers);
        System.out.println("Среднее: " + result);
    }
}
```

Ожидаемый вывод:

```text
Большее число: 12
Число 8 чётное: true
Среднее: 4.333333333333333
```

`NumberUtils` выполняет вычисления и возвращает результаты. `Main` вызывает методы и выводит результаты. Метод `main` — точка входа в нашу программу; библиотечному классу он не нужен.

### Шаг 6. Проверить методы

Проверяй обычные значения и граничные случаи:

```java
NumberUtils.max(10, 3);    // 10
NumberUtils.max(-8, -2);   // -2
NumberUtils.max(5, 5);     // 5

NumberUtils.isEven(6);    // true
NumberUtils.isEven(7);    // false
NumberUtils.isEven(0);    // true

NumberUtils.average(new int[]{2, 4, 6}); // 4.0
NumberUtils.average(new int[]{5});       // 5.0
NumberUtils.average(new int[]{});        // Исключение
```

Эти вызовы можно добавлять в `main`. Чтобы увидеть результат обычного вызова, оберни его в `System.out.println(...)`.

Проверку пустого массива выполняй отдельно: необработанное исключение прервёт дальнейшее выполнение программы.

## 7. Использование в другом проекте

Есть два основных варианта:

1. Добавить исходный файл `NumberUtils.java` в другой проект, сохранив пакет `mylibrary`.
2. Скомпилировать библиотеку, упаковать классы в JAR и подключить этот JAR к другому проекту.

JAR — архив, в котором можно распространять Java-классы и ресурсы. Для простой библиотеки создавать `module-info.java` не обязательно.

Одного `import` недостаточно, если самого класса или подключённой библиотеки нет в проекте.

## 8. Частые ошибки

### 1. Неправильное имя файла

В этом примере:

- `public class Main` сохраняется в `Main.java`.
- `public final class NumberUtils` сохраняется в `NumberUtils.java`.

### 2. Вызов без имени класса

Неправильно для нашего `Main`:

```java
max(3, 5);
```

Правильно:

```java
NumberUtils.max(3, 5);
```

### 3. Отсутствие static

В нашей библиотеке методы вызываются через имя класса. Поэтому у всех трёх методов сохраняем `static`.

### 4. Вывод вместо возврата

```java
System.out.println(a + b);
```

Эта команда печатает значение. Если метод должен вернуть результат для дальнейших вычислений, используется:

```java
return a + b;
```

### 5. Отсутствие проверки массива

До вычисления среднего нужно убедиться, что массив не равен `null` и содержит элементы. В нашем методе это проверяется в самом начале.

## 9. План практической работы

1. Определить назначение библиотеки.
2. Выписать методы: параметры и тип результата.
3. Создать класс в отдельном файле.
4. Реализовать методы.
5. Добавить Javadoc.
6. Создать `Main` для вызова методов.
7. Сравнить результаты с ожидаемыми.
8. Проверить граничные и недопустимые данные.
